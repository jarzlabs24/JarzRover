Install and connect

1
Prepare two Android phones.
Use one phone on the rover and one as the controller. The rover phone needs a USB OTG connection to the Arduino Nano.
2
Install the APKs.
Android may ask you to allow the browser or file manager to install unknown apps. Enable it temporarily, install the APK, then disable it again if desired.
3
Start the rover.
Connect the Robot phone to the Nano, turn on battery power, and open the JarzRover Robot app. Grant USB and camera permissions.
4
Connect the controller.
Open JarzRover Controller on the second phone and wait for the rover connection. Keep both phones on the same local network when using the phone controller.
5
Test safely.
Lift the rover for the first drive command, then test manual driving at low speed in a clear area. Try Object Tracking and Creature Lab only after the connection is stable.

FAQ and troubleshooting

Why can’t the app connect?

Confirm the Robot phone is connected to the Nano through USB OTG, battery power is on, USB permission was granted, and the controller is using the same local network.

Why do the motors not move?

Check battery and switch connections, the L298N motor-driver wiring, and the Nano firmware. Compare every signal and power connection with the wiring guide.

Where do I get help?

Check the full source and release notes before changing pins or firmware. For project support, contact jarzlabs24@gmail.com.
