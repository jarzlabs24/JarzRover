## Basic build preview

The reference body uses four TT gear motors, an Arduino Nano, an L298N motor driver, a battery and switch, an HC-SR04 sonar sensor, optional wheel-speed sensors, and an Android phone mount.

1. Print and clean the body, top plate, phone mount, and wheels.
2. Install the four motors and route their leads away from the gears.
3. Mount the motor driver, Nano, battery, switch, and front sensors.
4. Mount the phone and connect it to the Nano with USB OTG.
5. Follow the customer installation package for complete wiring, firmware, app, and test instructions.
