# JarzRover overview

JarzRover is a low-cost, 3D-printed rover from JARzLabs. It uses an Android phone as the robot computer and an Arduino Nano as the motor and sensor controller.

The public project includes the source code, project background, OpenBot attribution, compatibility notes, and a basic build preview. JarzLabs customer packages add version-matched binaries, complete printed-part files, full wiring, and support materials.
